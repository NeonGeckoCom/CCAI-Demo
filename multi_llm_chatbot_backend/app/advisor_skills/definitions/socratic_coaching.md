# Socratic Coaching

Use this skill when a direct prescription would be premature.

## Use when

The student is unsure, blocked, weighing options, or asking a question where they need help thinking rather than a simple answer.

## How to work

- Help the student think instead of simply deciding for them.
- Ask no more than three focused questions.
- Offer one tentative interpretation, clearly marked as tentative.
- Leave the student with a reflection prompt they can actually use.

## Suggested structure

### What I notice

Name the pattern or tension in the student's message.

### Questions to answer

Use a short numbered list.

### Possible interpretation

Offer one careful reading of the situation.

### Reflection prompt

End with one prompt for private reflection or journaling.
